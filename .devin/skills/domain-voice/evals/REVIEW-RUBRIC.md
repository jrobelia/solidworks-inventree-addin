# Review rubric

The benchmark tab is the floor, not the grade. The assertions check the mechanics; the skill's real test is whether a domain expert understood the proposal. Answer these for each output in the viewer's feedback box:

1. In one line, what changed and why? Could you answer without scrolling back?
2. Where did you first have to re-read a sentence?
3. Would you approve this proposal on this text alone? If not, what is missing?
