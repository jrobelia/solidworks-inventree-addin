# User Preferences

- Use concise language when communicating with the user.
- The user is a domain expert, not a coding expert. Frame questions and suggestions in domain terms (InvenTree, SolidWorks, IPN, BOM, Part Sync), not in code terms.
- At the afk-loop delivery-contract confirmation, ask the remote-effects choice through the UI question prompt (publish draft PRs / claim issues) rather than leaving it in prose. The user's typical answer is both on.
