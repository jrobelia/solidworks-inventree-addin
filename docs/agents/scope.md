# Scope

This add-in keeps the engineer inside SolidWorks.

## What it does

- Create InvenTree parts from SolidWorks parts and assemblies.
- Fetch InvenTree data and apply it to SolidWorks documents.
- Push SolidWorks document property values to InvenTree.
- Compare SolidWorks BOMs against InvenTree BOMs.

## Out of bounds

Stay inside the SolidWorks design workflow. Do not implement purchasing, build orders, supplier management, or other InvenTree workflows that belong in the web UI.
